ASSIGNMENT 1 · PROJECT BASELINE

Project brief and feasibility

Baseline context for the integrated Software Project Management mini-project.

Academic prototype
Problem statement

Manual software-project budgeting often relies on spreadsheets and inconsistent formulas, making estimates hard to compare and update.

Proposed solution

A browser-based tool calculates project cost, stores estimate history and brings SRS, planning, risks, team workload and SCM tracking into one workspace.

Objectives

Standardize cost estimates; make cost components transparent; support task, risk and resource coordination through a single local application.

Feasibility and scope

Uses Python, HTML/CSS/JavaScript and SQLite with no external Python packages, making it practical for a local college demonstration. Production security and external integrations remain future work.

Domain / SDG alignment

Software engineering and project management. Conceptually aligns with SDG 9 by applying digital tools to improve project planning and estimation.
